# Shuwei Zhao — Academic Homepage

Source code for [shuwei-zhao.github.io](https://shuwei-zhao.github.io), the academic homepage of Shuwei Zhao (Wayne), an Electronic Engineering undergraduate researcher at The Chinese University of Hong Kong.

The site highlights research in medical robotics, surgical robotics, and magnetic robotics, including miniaturized catheters and capsule robots for minimally invasive imaging and intervention.

## Local development

```bash
npm ci
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Main content

- `_pages/about.md` — biography, research interests, selected honors, and contact links
- `_projects/` — selected research projects
- `_bibliography/papers.bib` — publications
- `_news/` — research updates
- `_data/cv.yml` — web CV
- `assets/pdf/` — downloadable CV and research portfolio

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and hosted with GitHub Pages.
